# מאחורי הקלעים

אפליקציית PWA בעברית עם הסברים קצרים על איך דברים עובדים — מקרר, GPS, ברק, מסך מגע ועוד.
כל "דבר" עומד בפני עצמו: שאלת פתיחה, ארבעה שלבי מנגנון, טעות נפוצה, שתי שאלות בדיקה ומשפט אחד לקחת.

## הרצה

אין שלב בנייה. מגישים את התיקייה כאתר סטטי:

```
python3 -m http.server 8000
```

ופותחים את `http://localhost:8000`. ב־GitHub Pages מגישים את שורש הענף הראשי.

## קבצים

- `index.html` — המעטפת
- `css/app.css` — מערכת העיצוב: צבע אחד לפעולה, צבע התחום רק כהדגשה, והאיורים במרכז
- `app.js` — בית, פיד, ספרייה, "אני" (התקדמות וחזרה מרווחת), הגדרות והנגן
- `content.js`, `content-more.js`, `content-extra.js`, `content-inventions.js`, `content-wave3.js`, `history.js` — כל התוכן; מוסיפים "דבר" חדש כאובייקט נוסף ברשימה
- `fonts/` — הגופן Heebo (רישיון OFL, מצורף)
- `scenes/` — איור מונפש לכל דבר (`<id>.js`), ערכת הסגנון `scene.css`, וכלי תצוגה `preview.html?id=fridge`
- `lic.js` — קישורי הפעלה אישיים ומתגים לכל קישור (פיד, הדמיות, חזרה, תחומים). השרת ואפליקציית הניהול נמצאים ב-`dudutal-dev/Fitness-studio` (`worker/lic.js`, `admin/`); מזהה האפליקציה שם: `behind`. האכיפה כבויה כברירת מחדל, ובלי קישור הכול פתוח
- `sw.js` — עבודה בלי רשת
- `tools/release.mjs` — מריצים לפני כל העלאה: מעלה את מספר המטמון ובודק שכל איור והדמיה רשומים
- `tools/film_audit.py` — ביקורת הגייה לסרטונים (מבוסס על הכלי של MOVA): מתמלל את פס הקול של כל סרטון ומסמן מילים חשודות, עם חותמת זמן. כשיש תסריט ב-`videos/_src/<שם>.txt` ההשוואה היא מילה-מילה; בלי תסריט נשמר התמלול ב-`<שם>.heard.txt`. דורש `ffmpeg` ומפתח ElevenLabs (`XI_API_KEY`)
- `tools/smoke.cjs` — בדיקת עשן: עובר על כל המסכים בשתי הערכות ונכשל על שגיאה (דורש Playwright)
- `manifest.webmanifest`, `icon.svg` — התקנה למסך הבית

ההתקדמות נשמרת במכשיר בלבד (`localStorage`). בפתיחה האפליקציה שואלת את השרת רק אם נדרש קישור הפעלה; למי שהפעיל קישור, השרת רושם מתי האפליקציה נפתחה.

## הסרטונים הישנים (סגנון הקוד)

הם שמורים בהיסטוריה של הריפו, ב-commit `e4ae7d4c7b2c891e9029d91b353d43e3702a55fd`. לשחזור סרטון בודד:

    git show e4ae7d4c7b2c891e9029d91b353d43e3702a55fd:videos/<שם>.mp4 > videos/<שם>.mp4

הקוד שמייצר אותם נמצא בריפו ההפקה הפרטי.
